# 🚀 NoteQuest
### Your Life, Your Goals, Your Rewards.

**NoteQuest** is a modern, intelligent and reward-based personal productivity and life management application built with Flutter.

It combines note-taking, task management, goal tracking, personal planning and gamification in one place.

Our mission is to make everyday life more organized, productive and enjoyable.

---

## ✨ Features

### 📝 Smart Notes
- Create, edit and organize notes.
- Keep personal thoughts and important information.
- Organize notes into categories.
- Support for images and attachments.

### 🎯 Task Management
- Create and manage daily tasks.
- Track task completion.
- Set priorities and reminders.
- Monitor productivity progress.

### 🏆 Rewards & Gamification
- Earn XP and coins by completing tasks.
- Level-up system.
- Achievement badges.
- 3D reward badge designs.
- Motivation and progress tracking.

### 📅 Smart Calendar
- Daily, weekly and monthly planning.
- Important dates and special events.
- Birthdays, appointments and reminders.
- Holiday and special-day tracking.

### 🤖 AI-Powered Features
- AI-assisted note organization.
- Generate educational content from plans.
- Create and edit images using AI.
- Intelligent productivity assistance.

### 🌤️ Dynamic Experience
- Weather-based dynamic home screen.
- Light and dark themes.
- Smooth animations and visual effects.
- Personalized application settings.

### 🔐 Privacy & Security
- Personal encrypted vault.
- Secure notes.
- Backup and recovery.
- Device management and privacy controls.

## 🚀 Getting Started

### Requirements
- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android emulator or physical device

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd NoteQuest
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
